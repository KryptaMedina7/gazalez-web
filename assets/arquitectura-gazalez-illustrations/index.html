Configuración y límites

  • NEXT_PUBLIC_SITE_URL: URL base y metadatos; por defecto https://www.empresasgazalez.cl. Esto no demuestra qué dominio está conectado a Vercel.
  • NEXT_PUBLIC_CONTACT_EMAIL: destino comercial; por defecto contacto@empresagazalez.cl.
  • NEXT_PUBLIC_INDEXABLE: solo el valor true habilita indexación. No se han inspeccionado las variables remotas de Vercel.
  • Exportación estática y rutas con barra final; las páginas no declaradas devuelven 404.
  • En el código, cases y documents están vacíos; no hay un catálogo conectado de casos o fichas.
  • Las verificaciones locales no se representan como una canalización CI de pruebas: vercel.json solo configura instalación y build.
